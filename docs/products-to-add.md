## Procedure: add products and use the keywords

Run from `DOCTORS-OF-WHISKY/`. Each step is safe to re-run; nothing existing is deleted.

1. **Choose products.** Open `docs/products-to-add.csv` (same rows as the tables above). Start with priority A, then B, then C. Prices and sizes are listed; confirm stock and the supplier cost first. A product with no stock must not be listed.
2. **Preview, then add.**
   ```
   node scripts/add-products.mjs --dry-run --priority A
   node scripts/add-products.mjs --brand "Veuve Clicquot,Jameson Irish Whiskey"
   ```
   Each product is added with its size, the suggested price, the right collection (champagne, irish-whiskey, white-tequila and so on), a placeholder photo and stock 6. Rows whose collection cannot be decided are printed as `skip` so you can assign them by hand.
3. **Assign keywords from the bank.**
   ```
   node scripts/seo-tools/new-product-keywords.cjs
   ```
   Each new product gets one unique Transactional primary (highest volume that names the product), 15 Commercial-first secondaries and 20 Commercial tags, all KD 29 or lower, written to `SEO Analysis/mapping-v2.json`.
4. **Generate the pages.**
   ```
   node scripts/apply-keywords-v2.mjs
   node scripts/apply-seo-content.mjs
   ```
   This writes title, meta description, FAQs (5 per product, one keyword each), tags, alt text and the collection copy. Never edit the generated `lib/data/*-seo.ts` files by hand.
5. **Photos.** Name each photo after the product slug (`veuve-clicquot-brut-nv.jpg`), put it in `new whisky product pics/`, run `node scripts/process-images.mjs`, then replace `/images/products/coming-soon.svg` for that product. Alt text is generated from the product name and primary keyword.
6. **Verify.**
   ```
   npx tsc --noEmit && npm run build
   npx next start -p 3100
   node scripts/live-audit.mjs http://127.0.0.1:3100
   node scripts/integrity-audit.mjs http://127.0.0.1:3100
   node scripts/seo-score-audit.mjs http://127.0.0.1:3100
   node scripts/seo-tools/check-tags.mjs http://127.0.0.1:3100
   ```
   Targets: 0 failures, 0 broken links, every page 100%, 20 tags on each product.
7. **Re-enable the keywords.** Tags and taglines for brands that were unstocked are hidden automatically; they reappear once a matching product exists (the tag filter checks the catalogue search). Remove the brand from the `NOT_STOCKED` list in `SEO Analysis/home.js` and re-run `node home.js` so the homepage can use it.
8. **Publish and index.** Commit, push to `main`, wait for Vercel, then `node scripts/seo-tools/smcheck.mjs https://doctorsofwhisky.com.au`, `node scripts/seo-tools/indexnow.mjs`, and in Search Console request indexing for the new product and collection pages.
9. **Internal links.** Link each new product from its collection (automatic), from the matching blog guide if there is one, and from the gift or brand page (`lib/data/curated.ts`) where it belongs.

**Pricing rule used above:** price from the retailers in the list, x 1.08 rounded up to .99; re-check against the supplier cost so margin stays positive, and never list above the highest mainstream price (Dan Murphy's, BWS) for the same bottle.

**Do not** run `SEO Analysis/engine2.js` for this: it regenerates every page's keywords and would overwrite the 2026-10-11 re-map.
